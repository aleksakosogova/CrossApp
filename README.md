\# CrossApp

Наскрізний проєкт з крос-платформного програмування.



\## Предметна область

\- \*\*Назва\*\*: Замовлення

\- \*\*Сутності\*\*: Customer (клієнт), Product (товар), Order (замовлення), OrderLine (рядок замовлення).

\- \*\*Призначення\*\*: Оформлення замовлень та підрахунок загальної суми.



\## Структура рішення

\- `src/Core/` — бібліотека класів (містить логіку збору інформації про середовище `EnvironmentInfo`; у наступних тижнях тут з'являться папки `Dto/`, `Domain/`, `Storage/`).

\- `src/Cli/` — консольна точка входу (форматування та вивід результатів).



\## Запуск

```bash

dotnet build CrossApp.slnx

dotnet run --project src/Cli
